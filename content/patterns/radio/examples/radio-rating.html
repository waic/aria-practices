評価ラジオグループの例

この例について

以下は、ラジオグループパターンを示す評価入力の例です。 評価は、利用者が選択した星の数によって示されます。

類似の例は次のとおりです。

  • 評価スライダーの例: aria-valuetext を使用して、支援技術の利用者が 10 段階の満足度スケールで選択された現在の値の意味を理解しやすくする水平スライダー。
  • aria-activedescendant を使用したラジオグループの例: キーボードフォーカスを管理するために aria-activedescendant を使用するラジオボタングループ。
  • ロービング tabindex を使用したラジオグループの例: キーボードフォーカスを管理するためにロービング tabindex を使用するラジオボタングループ。

アクセシビリティ機能

  • ラジオを操作するときの認識性を高めるために、視覚的なキーボードフォーカス及びホバーは CSS を使用してスタイル設定されます:
    • フォーカスリングは 2 ピクセルの幅を持ち、それと星の境界線の間に少なくとも 2 ピクセルの間隔があります。
    • 星の上にカーソルを合わせるとカーソルがポインタに変わるため、評価の星がインタラクティブであることを認識しやすくなります。
  • ハイコントラスト設定が色を反転したときに、星の境界線及びフォーカスリングが背景と十分なコントラストを持つことを保証するために、境界線の色はテキストコンテンツの色と同期されます。 たとえば、フォーカスリングの境界線の色は、星の境界線を描画するインライン SVG polygon 及びフォーカスリングの境界線を描画するために使用される rect 要素の stroke プロパティに CSS currentcolor 値を指定することによって、ハイコントラストモードのテキストの前景色と一致するように設定されます。 polygon 及び rect 要素の背景をハイコントラストの背景色と一致させるために、rect の fill-opacity 属性はゼロに設定されます。 stroke 及び fill プロパティを指定するために代わりに特定の色が使用された場合、これらの色はハイコントラストモードでも同じままであり、星と背景の間のコントラストが不十分になるか、色がハイコントラストモードの背景と一致した場合には見えなくなる可能性さえあります。
    注: SVG 要素は、currentcolor 値がハイコントラストモードで更新されるために、CSS forced-color-adjust プロパティを auto に設定する必要があります。 一部のブラウザはデフォルト値に auto を使用しません。

キーボードのサポート

キー 機能
Tab
  • radiogroup 内のチェックされている radio ボタンにフォーカスを移動します。
  • radio ボタンがチェックされていない場合、フォーカスはグループの最初の radio ボタンに移動します。
スペース
  • フォーカスのある radio ボタンがチェックされていない場合、状態を checked に変更します。
  • それ以外の場合、何も行いません。
  • 注記: ラジオがチェックされていない状態は、ページロード時にのみ発生します。
下矢印
右矢印
  • グループ内の次の radio ボタンにフォーカスを移動し、チェックします。
  • フォーカスが最後の radio ボタンにある場合、フォーカスを最初の radio ボタンに移動します。
  • 以前にチェックされていたラジオボタンの状態はチェックされていないに変更されます。
上矢印
左矢印
  • グループ内の前の radio ボタンにフォーカスを移動し、チェックします。
  • フォーカスが最初の radio ボタンにある場合、フォーカスを最後の radio ボタンに移動し、チェックします。
  • 以前にチェックされていたラジオボタンの状態はチェックされていないに変更されます。

ロール、プロパティ、ステート、及び tabindex 属性

ロール 属性 要素 使い方
none svg SVG 要素に none ロールを使用することで、支援技術が SVG 要素を画像又はその他のロールとして解釈しないようにします。
radiogroup div
  • div 要素を radio ボタンのグループのコンテナとして特定します。
  • 以下に説明するロービング tabindex 戦略を使用してフォーカスが管理されるため、フォーカス可能ではありません。
aria-labelledby="ID_REFERENCE" div ラジオグループのラベルを含んでいる要素を参照します。
radio g g 要素を ARIA radio ボタンとして特定します。
aria-label="name" g ラジオボタンに関連付けられている星の数を特定するアクセシブルな名前を定義します (例: "星 1 つ"、"星 2 つ"、...)。
tabindex="-1" g
  • 要素をフォーカス可能にしますが、ページの Tab シーケンスには含めません。
  • ページの Tab シーケンスに含まれる 1 つを除く、ラジオグループに含まれるすべてのラジオボタンに適用されます。
  • このフォーカス管理のアプローチは、ロービング tabindex を使用したコンポーネント内のフォーカス管理の実践で説明されています。
tabindex="0" g
  • ラジオボタンをフォーカス可能にし、それをページの Tab シーケンスに含めます。
  • ラジオグループ内の 1 つのラジオにのみ設定されます。
  • ページの読み込み時に、ラジオグループの最初のラジオボタンに設定されます。
  • ラジオグループ内のフォーカスとともに移動するため、最も最近フォーカスされたラジオボタンがページの Tab シーケンスに含まれます。
  • このフォーカス管理のアプローチは、ロービング tabindex を使用したコンポーネント内のフォーカス管理の実践で説明されています。
aria-checked="false" g
  • チェックされていない radio ボタンを特定します。
  • CSS 属性セレクタ (例: [aria-checked="false"]) を使用して、視覚的な状態を aria-checked 属性の値と同期します。
  • オペレーティングシステム及びブラウザのハイコントラスト設定をサポートするために、CSS の ::before 疑似要素をチェックされていないラジオボタンの視覚的な状態を示すために使用します。
aria-checked="true" g
  • チェックされている radio ボタンを特定します。
  • CSS 属性セレクタ (例: [aria-checked="true"]) を使用して、視覚的な状態を aria-checked 属性の値と同期します。
  • オペレーティングシステム及びブラウザのハイコントラスト設定をサポートするために、CSS の ::before 疑似要素をチェックされているラジオボタンの視覚的な状態を示すために使用します。
