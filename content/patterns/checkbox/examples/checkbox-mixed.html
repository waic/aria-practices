チェックボックスの例（混合状態）

この例について

この例では、チェックボックスのパターンを使用して、三値状態、又は混合状態のチェックボックスを作成する方法を示します。 この実装では、混合状態のチェックボックスは、複数の標準 HTML チェックボックスのセットの状態を表します。 セット内のチェックボックスがどれもチェックされていない場合、混合状態のチェックボックスはチェックされず、セットのすべてのメンバーがチェックされている場合、混合状態のチェックボックスはチェックされます。 セットにチェック済みのチェックボックスと未チェックのチェックボックスの両方が含まれている場合、混合状態のチェックボックスは部分的にチェックされます。 三値状態のチェックボックスをアクティブにすると、セット内のチェックボックスの状態が変更されます。

類似の例は次のとおりです。

  • チェックボックス（二値状態）: シンプルな二値状態のチェックボックス。

アクセシビリティ機能

  • 支援技術の利用者が、チェックボックスがすべて「サンドイッチの調味料」という名前の関連チェックボックスのグループの一部であることを理解できるように、チェックボックスは legend 要素でラベル付けされた fieldset 要素でラップされています。
  • ラベル又はチェックボックスのいずれかをクリックするとチェックボックスが動作することを知覚しやすくするために、ポインターがチェックボックス又はラベルのいずれかにホバーすると、背景色が変わり、境界線が表示され、カーソルがポインターに変わります。
  • オペレーティングシステムのハイコントラスト設定が有効になっている場合、一部のシステムでは透明に設定された境界線が可視化されるため、フォーカスされている要素と他の要素との間に視覚的な違いを作成するために透明度を使用することはできません。 透明度を使用する代わりに、フォーカスされた要素はより太い境界線とより少ないパディングを持ちます。 要素がフォーカスを受け取ると、その境界線は0から2ピクセルに変わり、パディングは2ピクセル減少します。 要素がフォーカスを失うと、その境界線は2ピクセルから0に変わり、パディングは2ピクセル増加します。
  • ハイコントラスト設定で色が反転した場合に、CSS のインライン SVG チェックボックスグラフィックの境界線が背景と十分なコントラストを持つようにするために、境界線の色はテキストコンテンツの色と同期されます。 たとえば、チェックボックスの境界線の色は、チェックボックスを描画するために使用される rect 及び polyline 要素の stroke プロパティに CSS currentcolor 値を指定することにより、ハイコントラストモードテキストの前景色と一致するように設定されます。 チェックボックスグラフィックの背景をハイコントラストの背景色と一致させるには、rect 要素の fill-opacity 属性をゼロに設定します。 代わりに特定の色を使用して stroke 及び fill プロパティを指定した場合、それらの色はハイコントラストモードで同じままであり、チェックボックスと背景の間のコントラストが不十分になったり、色がハイコントラストモードの背景と一致した場合はチェックボックスが見えなくなったりする可能性があります。
    注：SVG 要素は、ハイコントラストモードで currentcolor 値を更新するために、CSS forced-color-adjust プロパティを auto に設定する必要があります。 一部のブラウザーでは、デフォルト値に auto を使用しません。

キーボードのサポート

キー 機能
Tab チェックボックス間でキーボードフォーカスを移動します。
Space
  • 三値状態のチェックボックスを、チェックなし、混合、チェック済みの状態で切り替えます。
  • 三値状態のチェックボックスがオフの場合、制御されているすべてのチェックボックスはオフになります。
  • 三値状態のチェックボックスが混合されている場合、制御されているチェックボックスは、三値状態のチェックボックスが最後に混合されたときに持っていた状態の最後の組み合わせ、又はページが読み込まれたときに持っていた状態のデフォルトの組み合わせに戻ります。
  • 三値状態のチェックボックスがオンの場合、制御されているすべてのチェックボックスがオンになります。

ロール、プロパティ、ステート、及び Tabindex 属性

ロール 属性 要素 使用法
checkbox div
  • div 要素を checkbox として識別します。
  • この div の子テキストコンテンツは、チェックボックスのアクセシブルな名前を提供します。
tabindex="0" div チェックボックスをページのタブシーケンスに含めます。
aria-controls="[IDREFS]" div 混合チェックボックスによって制御されるチェックボックスのセットを識別します。
aria-checked="false" div
  • 三値状態の checkbox がチェックされていないことを示します。
  • この状態では、制御されているすべてのチェックボックスのチェックが外されています。
  • CSS 属性セレクター（例：[aria-checked="false"]）は、視覚的な状態を aria-checked 属性の値と同期させるために使用されます。
  • オペレーティングシステムとブラウザーのハイコントラスト設定をサポートするために、CSS ::before 疑似要素と content プロパティを使用して、チェックボックスの状態の視覚的なインジケーターを生成します。
aria-checked="true" div
  • 三値状態の checkbox がチェックされていることを示します。
  • この状態では、制御されているすべてのチェックボックスがチェックされています。
  • CSS 属性セレクター（例：[aria-checked="true"]）は、視覚的な状態を aria-checked 属性の値と同期させるために使用されます。
  • オペレーティングシステムとブラウザーのハイコントラスト設定をサポートするために、CSS ::before 疑似要素と content プロパティを使用して、チェックボックスの状態の視覚的なインジケーターを生成します。
aria-checked="mixed" div
  • 三値状態の checkbox が混合されていることを示します。
  • この状態では、一部の制御されたチェックボックスはチェックされておらず、一部はチェックされています。
  • CSS 属性セレクター（例：[aria-checked="mixed"]）は、視覚的な状態を aria-checked 属性の値と同期させるために使用されます。
  • オペレーティングシステムとブラウザーのハイコントラスト設定をサポートするために、CSS ::before 疑似要素と content プロパティを使用して、チェックボックスの状態の視覚的なインジケーターを生成します。
