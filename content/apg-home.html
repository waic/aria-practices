ARIA Authoring Practices Guide (APG) ホーム

Accessible Rich Internet Application (ARIA) 仕様で定義されたアクセシビリティのセマンティクスを使用して、アクセシブルなウェブ体験を作成する方法を学びましょう。 このガイドでは、一般的なデザインパターン及びウィジェットにアクセシビリティのセマンティクスをどのように適用するかを説明します。 デザインパターンと機能する例に加え、基礎的な実践事項に関する詳細なガイダンスを提供します。

APG のリソース

  • デザインパターンと例

    ARIA のロール、ステート、プロパティ及びキーボードサポートの実装によって、アクセシブルなウェブコンポーネント及びウィジェットを作成する方法を学びます。 各パターンの実装方法は、機能する例で 1 つ以上示されます。

    詳細を見る

  • ARIA ランドマークの使用

    HTML のセクショニング要素及び ARIA ランドマークロールを使用して、支援技術の利用者がページのレイアウトの意味を理解しやすくする方法を学びます。

    詳細を見る

  • アクセシブルな名前 (name) 及び説明 (description) の提供

    アクセシブルな名前を、そして適切な場合にはアクセシブルな説明を要素に提供することは、アクセシブルなウェブ体験を開発する際に作成者が担う最も重要な責務の 1 つです。

    詳細を見る

参加する

APG タスクフォースは、APG の有用性と品質を継続的に向上させるため、広範なコミュニティの代表者及び参加者に支えられています。 あなたが関わり、アクセシブルな体験の開発を後押しできる方法は様々あります。

  • タスクフォースに参加する

    APG タスクフォースへの参加を希望される方は、まず W3C ARIA ワーキンググループへの参加が必要です。 参加者にはタスクフォースの活動への積極的な貢献が求められます。

    タスクフォースの活動内容及び参加方法について詳しく学ぶ

  • GitHub 経由で貢献する

    多くの貴重な貢献は、GitHub リポジトリで関心のあるイシューを見つけたり提起したりし、GitHub プルリクエストで変更案を提出する人々によってなされています。 この道を選ぶ場合は、まずリポジトリへの貢献方法及びコード品質の維持に関するガイドラインをご確認ください。

    GitHub リポジトリの ReadMe を見る

  • メーリングリスト

    APG タスクフォースは公開の aria-practices メーリングリストをメールでの議論に使用しています。 会議のアナウンス、アジェンダ、議事録へのリンクはメーリングリストに送信されます。 APG のコンテンツについて議論する場所としては GitHub イシューが推奨されますが、メーリングリストは APG タスクフォースとメールでコミュニケーションを取りたい方であれば誰でも利用できます。
